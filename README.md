* 🌳 **EcoDataAl / ReVerdecer Piura:** Registro de árboles urbanos en mapa interactivo con datos climáticos de Open-Meteo, trabajo bajo GitFlow y enfoque en backend y modelo de datos. *(Next.js, PostgreSQL)*
